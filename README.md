# Python Basics

A beginner-friendly Python repository containing basic programming practice and academic practicals.

## About the Project

This repository is created to practice Python programming and maintain practical work on GitHub.

## Programs

### 1. Factorial Program (`factorial.py`)

This program calculates the factorial of a number entered by the user using a `for` loop.

**Example:**
```text
Enter a number: 5
Factorial is: 120
```

## How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python factorial.py
```

## Requirements

- Python 3
- No external Python packages are required for the factorial program.
